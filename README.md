# Nogler's frontend movile
This will be the frontend movile for "Nogler", a multiplayer game based on "balatro" by LocalThunk, focused on creating a entertaining experience for players, in a multiplayer environment.

## Authors

- [@Emilliano-Recuenco](https://github.com/Misterxd12)

- [@Jorge-Gallardo](https://github.com/JGallJ)

## Creating a project

```bash
flutter create nogler
```

## Download dependencies

```bash
flutter pub get
```
## Run with VS Code 
- Open the project in **Visual Studio Code**.
- Press **Fn + F5** to start debugging.
- Select the target **emulator** or **physical device** if prompted.

## Run from the terminal

```bash
flutter run
```
## Running in different modes

Debug: The default mode. Includes debugging tools, hot reload, and logs.

```bash
flutter run --debug
```

Profile: Used to measure performance with minimal debugging overhead.

```bash
flutter run --profile
```

Release: The optimized version for production, with debugging tools disabled.

```bash
flutter run --release
```

##  Building an APK

```bash
flutter build apk
```
